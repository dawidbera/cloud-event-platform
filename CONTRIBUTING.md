# Contributing to Cloud Event Processing Platform

Thank you for your interest in contributing! This project is primarily a learning and portfolio piece, but contributions, suggestions, and bug reports are welcome.

## How to Contribute

1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/my-feature`).
3. Commit your changes (`git commit -am 'Add some feature'`).
4. Push to the branch (`git push origin feature/my-feature`).
5. Open a Pull Request.

## Development Standards

- **Python**: Ensure your code passes `ruff` and `mypy` checks.
- **Tests**: Write `pytest` unit tests for any new logic.
- **Commit Messages**: Write clear, descriptive commit messages.

## Bug Reports and Feature Requests

Please open an issue describing the bug or feature request in detail. Provide steps to reproduce for bugs.
